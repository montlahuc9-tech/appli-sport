# Minuteur Sport — appli de test

Appli web installable (comme une vraie appli) : séances maison / salle par groupe musculaire,
minuteur avec sifflet et « one, two, three », photos des exercices, muscles travaillés, séances perso.

- Pour l'installer : ouvrir le lien sur le téléphone, puis « Ajouter à l'écran d'accueil ».
- Comptes : par défaut, l'inscription (prénom + e-mail) est gardée sur le téléphone.
  Pour de vrais comptes en ligne, remplir `config.js` avec les clés Supabase (voir `supabase.sql`).
- Après une modification : changer `VERSION` dans `sw.js` pour que les téléphones prennent la nouvelle version.
- Photos : Free Exercise DB (domaine public).
